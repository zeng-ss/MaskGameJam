## 排查并修复 Unity 编辑器日志报错

用户反馈编辑器报错，从 `Logs/Editor.log` 与 `Logs/AssetImportWorkerHW*.log` 入手，定位到三类问题：

1. **UPM 启动失败**：`[Package Manager] 'projectVersion' '2022.3.62f3c1' is not a valid Unity version`，`update-dependencies` 返回 400。成因是项目从团结引擎迁到 Unity 6 时 ProjectVersion.txt 尚未更新。现已是 6000.5.9f1，属自愈。

2. **字体资源加载失败**：`Assets/Res/Font/AlimamaDongFangDaKai-Regular SDF.asset` 报 "File may be corrupted or was serialized with a newer version of Unity"。实际为 134 字节 Git LFS 指针，未拉真实内容。执行 `git lfs pull --include=...` 恢复为 134 MB 的 TMP_FontAsset。同时补全了 HybridCLR 的 4 个 LFS dll（后续随 HybridCLR 一起删除）。

3. **HybridCLR 包被删导致 asmdef 失效引用**（主因）：`Packages/com.code-philosophy.hybridclr` 288 个文件在工作区处于 deleted 状态，`AOT.asmdef` 引用的 `13ba8ce6…`（HybridCLR.Runtime）和 `ProjectEditor.asmdef` 引用的 `2373f786…`（HybridCLR.Editor）找不到，导致 AOT、HotUpdate、PriorityHotUpdate、ProjectEditor 全部无法编译。

用户选择彻底移除 HybridCLR（准备改 Lua 热更），据此完成：
- `Assets/Scripts/AOT/AOT.asmdef`：移除失效 GUID
- `Assets/Scripts/ProjectEditor/ProjectEditor.asmdef`：移除失效 GUID
- `Assets/Scripts/ProjectEditor/Build.cs`：删除 GenerateDllFiles 与 HybridCLR 依赖，NewClient/UpdateClient 只保留构建与 Addressables 增量更新
- `Assets/Scripts/AOT/HotUpdateSystem.cs`：删除 using HybridCLR 与 LoadMetadataForAOTAssemblies 及其调用
- 删除 `Packages/com.code-philosophy.hybridclr`、`ProjectSettings/HybridCLRSettings.asset`、`HybridCLR.Editor.csproj`、`HybridCLR.Runtime.csproj`

## 第二轮：修复 CS0619（Unity 6 废弃 API）

用户反馈真实报错是编译错误：
```
AutoPoolFindPoolHandler.cs(24,28): error CS0619: 'Object.GetInstanceID()' is obsolete: 'Use GetEntityId instead.'
```
同类报错还出现在 `com.unity.addressables`、`com.unity.visualscripting` 的 PackageCache 源码里（用户自行解决了那两个，未介入）。

项目内只有 AutoPool 插件用到 `GetInstanceID()`（2 处）。改为 `GetEntityId()` 后，int ID 沿调用链传播，共改 4 个文件 7 处：
- `AutoPoolFindPoolHandler.cs`：`int` → `EntityId`，2 处 `GetInstanceID()` → `GetEntityId()`，`Dictionary<string,int>` → `Dictionary<string,EntityId>`
- `MainAutoPool.cs`：`PoolDic` → `Dictionary<EntityId, PoolInfo>`，`ResourcesPoolDic` → `Dictionary<string, EntityId>`，`RegisterPool`、`IsActiveRoutine` 参数改 `EntityId`
- `AutoPoolCreatePoolHandler.cs`：`RegisterPool` 参数改 `EntityId`
- `AutoPoolLifeHandler.cs`：`IsActiveRoutine` 参数改 `EntityId`
